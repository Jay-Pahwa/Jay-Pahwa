##  Featured Projects

###  [BankNet – Multi-Bank Loan Management Platform](https://github.com/Jay-Pahwa/banknet)
> Java · Spring Boot 3.4 · MySQL 9.2 · REST API · JWT · HTML/CSS/JS

A full-stack FinTech platform that onboards small regional cooperative banks onto a unified loan management system. Customers can compare interest rates across all registered banks through a public portal.

-  Three-tier role architecture (Super Admin → Bank Admin → Customer) with JWT auth & RBI KYC-compliant onboarding
-  Dynamic **Trust Score Engine** (0–100) gating loan eligibility up to ₹10 lakh
-  Emergency Micro-Loan module — instant disbursement up to ₹1 lakh at 2% flat for eligible customers
-  20 REST endpoints · 6 Spring Boot controllers · 13 normalised MySQL tables

---

###  [Star, Quasar & Galaxy Classifier – ML + 3D Web Visualisation](https://github.com/Jay-Pahwa/sdss-celestial-classifier)
> Python · Scikit-learn · Random Forest · SVM · KNN · PCA · Three.js / WebGL

Ensemble ML pipeline on SDSS DR17 (10,000 samples) classifying celestial objects using photometric features and redshift.

-  Voting Classifier combining Decision Tree, SVM, Random Forest & KNN via Ensemble Learning
-  PCA to 3 components for dimensionality reduction + interactive 3D scatter plots
-  Interactive WebGL / Three.js 3D visualisation for exploring classified objects in-browser
